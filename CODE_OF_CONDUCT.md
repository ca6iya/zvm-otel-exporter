# Code of Conduct

This project follows the [LF Projects, LLC Code of Conduct](https://lfprojects.org/policies/code-of-conduct/).

That policy applies to everyone participating in issues, discussions, pull requests, and any future meetings. Do not paste a second copy of the policy into this repository.

To report a conduct concern, use the contact method published on that page. Do not file a public issue for a report that includes private details.
