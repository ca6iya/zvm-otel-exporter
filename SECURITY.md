# Security policy

## Supported versions

Security fixes apply to the latest 0.2.x release and to the `main` branch.

| Version | Supported |
| --- | --- |
| 0.2.x | yes |
| 0.1.x | no |
| `main` | yes |

## Reporting a vulnerability

Report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/ca6iya/zvm-otel-exporter/security/advisories/new).

Do not open a public issue, discussion, or pull request that describes the vulnerability, and do not include exploit details, tokens, or credentials.

The repository owner has to enable private vulnerability reporting before that form accepts submissions. If the form is unavailable, open a public issue that says only that you need a private security channel. Do not include the vulnerability itself.

## Response

Maintainers aim to acknowledge a private report within 7 days and to share a remediation plan, or a clear status, within 30 days of confirming the issue. A fix is released by the process in [RELEASE.md](RELEASE.md), with credit to the reporter unless they ask to stay anonymous.
